# 🚀 StarBoys

Um projeto front-end simples e estilizado, desenvolvido para faculdade contendo HTML e CSS. Inspirado em uma temática espacial e visualmente agradável, o site apresenta uma página principal com estrutura clara e responsiva.

## 🔧 Tecnologias Utilizadas

- HTML5
- CSS3
- JS

## 📌 Funcionalidades

- Página inicial com visual atrativo
- Layout responsivo para diferentes tamanhos de tela
- Estilização personalizada com fontes, cores e animações

## 🎯 Objetivo

Este projeto foi desenvolvido com fins educacionais, para consolidar conhecimentos em estruturação de páginas web e design com CSS puro.
